# OpenBallance keyboard layout for gasm (gasm-run --keymap FILE; the browser player's default):
# <pad> <button> <key code>...  (KeyboardEvent.code names). Pad 1 is what the game reads (src/app.c):
# d-pad = arrows, A / Start = Enter, B = Esc, X = Space, L / R = left Shift (view rotation), Y = Q,
# Select = F1. Both Shift keys are on L so that Shift + arrows rotate the view as in the original.
# player 1
1 up ArrowUp
1 down ArrowDown
1 left ArrowLeft
1 right ArrowRight
1 a KeyX
1 b KeyZ
1 x KeyS Space
1 y KeyA
1 l ShiftLeft ShiftRight KeyQ
1 r KeyW
1 select F1
1 start Enter NumpadEnter
# player 2 (used while fewer than two gamepads are connected)
2 up KeyI
2 down KeyK
2 left KeyJ
2 right KeyL
2 a Period
2 b Comma
2 x KeyM
2 y KeyN
2 l KeyU
2 r KeyO
2 select Backspace
2 start ControlRight
