# Installing

## Bundles

Each [release](https://github.com/emdzej/openballance/releases) has ready-to-run bundles of
`openballance.wasm` with the gasm runner:

| System | File |
|---|---|
| macOS (Apple Silicon and Intel) | `openballance-gasm-<version>-macos-universal.zip` (contains `Ballance (gasm).app`) |
| Linux x86_64 / arm64 | `openballance-gasm-<version>-linux-<arch>.tar.gz` |
| Windows x86_64 | `openballance-gasm-<version>-windows-x86_64.zip` |

Unpack it and start the launcher (`Ballance (gasm).app`, `openballance.sh` or `OpenBallance.cmd`). The
first time, it asks where your [game data](/guide/game-data) is and remembers the answer.
