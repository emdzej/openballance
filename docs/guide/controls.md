# Controls

OpenBallance reads the keyboard and the mouse directly (gasm 0.5's raw input), so the controls are the
original's, and the keys can be changed in the game's own Options.

| Key | Game |
|---|---|
| Arrow keys | roll the ball, move in menus |
| Enter | select, continue the tutorial |
| Esc (tap) | pause menu, back |
| Shift + Left / Right | rotate the view by 90° |
| Space | raise the view |
| Q | skip the tutorial |
| Mouse | the menus: move it to show the cursor, then point and click |

**Holding Esc** for a second quits `gasm-run` (in the browser it stops the game). In fullscreen the
browser itself takes Esc to leave fullscreen.

A gamepad works as well: the d-pad rolls the ball, A and Start select, B pauses, the shoulder buttons with
the d-pad rotate the view, X raises it and Y skips the tutorial.
