# Controls

gasm gives every game the same gamepad-style controls; OpenBallance maps them onto the keys Ballance
expects. Keyboard defaults:

| Key | Game | Ballance key |
|---|---|---|
| Arrow keys | roll the ball, move in menus | arrows |
| Enter or X | select, continue the tutorial | Return |
| Z | pause menu, back | Esc |
| W held + Left / Right | rotate the view by 90° | left Shift + arrows |
| S | raise the view | Space |
| A | skip the tutorial | Q |
| Right Shift | | F1 |

Q works as Shift too, but it also types a "q", which the tutorial reads as "skip": use **W**.
A gamepad works too: the d-pad rolls the ball, A and Start select, B pauses, the shoulder buttons rotate
the view, X raises it.

Esc quits `gasm-run` itself.
