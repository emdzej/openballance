Play Ballance in your browser

OpenBallance runs here as openballance.wasm on the gasm runtime: the same engine as on the desktop, running the original game's scripts, levels, textures, sounds and music from your own copy of Ballance. Nothing from the game is on this site, and nothing you pick leaves your computer.

What you need

  • Ballance (Cyparade / Atari, 2004): the folder you installed it to (the one with base.cmo), the CD (the folder with Setup), or an image of the CD (.iso or a raw .bin).
  • A browser with WebGPU: a recent Chrome or Edge, Safari 26 or newer, or Firefox 141 or newer on Windows.
  • About 150 MB of browser storage: the page copies the data into its private storage for this site once, so later visits start at once.
  • A keyboard or a gamepad.

The installed game (for example C:\Program Files\Ballance, with base.cmo, 3D Entities, Sounds and Textures), or the CD itself or a copy of it (with Setup\data1.hdr): the game is read straight from the installer's cabinets, no installation needed.

    Importing copies the files into this site's private browser storage (OPFS). Playing without importing reads them from what you picked, which you'll need to pick again next time.

    Controls

    gasm gives the game a gamepad; OpenBallance turns it into the keys the original reads. A connected gamepad works too. More in Controls.

    PadOriginal keyIn the gameYour keys

    Esc is not used (browsers keep it for leaving fullscreen): pause with the B key (Z by default). Highscore names are typed on the keyboard. Highscores and the options are kept in this browser.

    Keyboard layout

    One binding per line: <pad 1-4> <button> <key code>.... Buttons: a b x y l r select start up down left right; key codes are KeyboardEvent.code names. The same format as gasm-run --keymap. The game reads pad 1.
